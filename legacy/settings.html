Worker capacity

Choose how many workers Forge can run at once. Changes apply as workers become available.

The total is shared across roles. For example, a total of 1 means only one builder, reviewer or auditor can work at a time, even if a role’s limit is higher.

Destructive action

Reset Forge

Stops all Forge workers, discards unfinished local work, and clears this factory’s setup and saved connections. You will need to set up Forge again.

Your GitHub issues, branches, pull requests and App registrations are preserved.

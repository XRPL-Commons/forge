Set up the GitHub Apps
  1. In your GitHub account or organization settings, open Developer settings → GitHub Apps → New GitHub App. Create a separate App for each role below.
  2. Use your account URL as the homepage. Leave user authorization, callback URLs, and device flow off. Disable webhooks; Forge polls for changes.
  3. Grant the repository permissions listed on each role card. Leave organization permissions unset. Metadata read access is included by GitHub.
  4. Install every App on the same selected repositories. Repository access is granted in GitHub; refreshing here only reads it.
  5. Generate each App's private key and store it privately on the server. Set an environment variable to its absolute file path. Enter that variable's name below, together with the App ID and the installation ID from GitHub's installation settings URL.
